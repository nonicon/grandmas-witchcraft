One word: the word a grandma would text about AI. She doesn't reach for a manual — she reaches for the one word that covers anything she can't see working. The kettle that talks back, the phone that finishes her sentences, the machine that seems to know things. Her warm, baffled verdict on all of it, in a single word:

**Witchcraft**

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt` (1–30 characters, a single plain word, exactly as the sealed gate requires).
